# Documentation build dependencies for MkDocs
#
# These dependencies are used by the docs workflow to build
# the MkDocs-based API reference documentation.
#
# Install with: pip install -r requirements-docs.txt
#
# ---------------------------------------------------------------------
# This file is a full lock, not a shortlist.
#
# The docs workflow does not merely build the site - it rebuilds it and
# fails if the result differs from the committed docs/mkdocs by a single
# byte. A byte-exact gate needs a byte-exact input: with only the direct
# dependencies pinned, a release of any transitive one changed the
# generated HTML while no file in this repository changed, and the check
# then failed on a commit that had nothing to do with the docs.
#
# Every version below is the newest release as of 2026-08-06, so this
# freezes the current state rather than an old one.
#
# To regenerate after a deliberate upgrade:
#   python -m venv /tmp/docs && /tmp/docs/bin/pip install mkdocs \
#     mkdocs-material "mkdocstrings[python]" Pygments
#   /tmp/docs/bin/pip freeze
# then bring the versions across, keep the marker on colorama, and commit
# the regenerated docs/mkdocs alongside.
#
# Resolved on Windows. Every entry is available for Linux at the same
# version, and colorama - the one Windows-only package, required by click
# and mkdocs - keeps its environment marker so it is not installed there.
# ---------------------------------------------------------------------

# --- What the documentation is actually built with --------------------

# Python docstring parsing plugin for MkDocs
